Seção 2

Diagrama de Objetos

Fluxo principal de dados, do primeiro contato com o lead até o acompanhamento pós-venda/laboratório. Atualizado conforme o BRD oficial (Parte 3).

Leitura do diagrama

  • Lead → Account/Contact/Opportunity: conversão padrão do Salesforce, associando a oportunidade à linha de produto de interesse.
  • Opportunity → Product2/PricebookEntry: via OpportunityLineItem, para os dois caminhos comerciais (Caminho A produto existente, Caminho B a desenvolver).
  • Opportunity → Amostra__c: relação Lookup (BRD 3.5.2) — cada amostra enviada ao cliente é um registro relacionado à oportunidade, permitindo múltiplas tentativas rastreadas. Amostra__c tem OWD próprio (Public Read Only), pois não herda de um pai Master-Detail.
  • Amostra__c → Case: quando uma amostra é reprovada, um Case é criado (campo AmostraId__c, Lookup) e roteado à fila do laboratório.

Seção 4

Security Model

Status atualizado (v1.1): os Permission Sets Vendedor e Laboratorio já existem na org — criados fora do fluxo Claude por um mentor do hackathon, reconciliados via retrieve e registrados em evidencias/log.md (ver ADR 0004). Nenhum usuário tem os Permission Sets atribuídos ainda. O Permission Set Administrador Comercial e a Queue "Laboratório" ainda não existem.

Organization-Wide Default (OWD)

ObjetoOWDEfeito
AccountPublic Read OnlyTodo vendedor lê qualquer conta; só o owner edita
OpportunityPublic Read OnlyTodo vendedor lê qualquer oportunidade; só o owner edita
CasePublic Read OnlyLeitura geral; edição pelo owner (vendedor ou químico da fila)
Amostra__cPublic Read OnlyOWD próprio (não herda de pai, pois a relação é Lookup)
Lead / Product2Padrão da plataformaSem requisito de restrição adicional do cliente

Public Read Only nesses objetos já entrega "lê tudo, edita só o próprio" nativamente (owner mantém edição) — sem necessidade de sharing rules adicionais para esse requisito específico do cliente.

Permission Sets

Vendedor já existe

CRUD em Lead/Account/Opportunity/Case que possui; leitura nos demais; sem acesso à aprovação de preço.

Laboratório / Químico já existe

Sérgio e André. Acesso à fila de Case "Laboratório"; CRUD em Case; leitura em Opportunity/Account relacionados.

Administrador Comercial pendente

Gabriel Jacob. Acesso total; aprovador do fluxo de preço/desconto; visão de todos os relatórios e dashboards.
