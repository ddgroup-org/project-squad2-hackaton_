# Evidências de uso do Claude/IA

Esta pasta existe para atender ao critério de avaliação do hackathon que pesa **25% da nota**: uso do Claude/IA na implementação (ver [project-context.md](../project-context.md)).

## Estrutura

- `log.md` — histórico de cada demanda executada: o que foi pedido, o que foi feito, e o commit correspondente.
- `demandas/` — cópia arquivada do `demanda.md` no momento em que cada demanda foi executada.
- `prints/` — capturas de tela da org/execução, quando fizer sentido registrar visualmente.

## Como usar

Ver [docs/como-executar-demandas.md](../docs/como-executar-demandas.md) para o fluxo completo (escrever a tarefa em `demanda.md`, rodar `/executar-demanda NN`).

## Atenção

Este repositório é **público**. `scripts/capturar-print.sh` tira um print da **tela inteira** — feche ou minimize o que estiver fora do escopo do hackathon antes de rodar, e confira o arquivo gerado antes de dar commit/push. Captura de tela é sempre uma ação deliberada (não roda automaticamente) por esse motivo.
